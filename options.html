Capture to Noesis

Connect to your Noesis Knowledge Engine. Captures are sent only when you click Save or Retry.

The token is stored in this Firefox profile, without browser sync. Use a dedicated caller token with intake and namespace read/write scopes.

Optional Modulo result routing

When routing is enabled on a capture, the extension adds a source/session reference to Life/PARA/Resources linked to the selected object. It does not copy page text or overwrite notes. Expired tokens must be replaced.
